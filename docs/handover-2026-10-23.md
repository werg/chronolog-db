## Bugs fixed (each with a regression test)

1. **Duplicate genesis recovery keys** (`packages/capabilities/src/codec.ts`).
   A genesis could list the same recovery public key three times, letting one
   custodian satisfy the 2-of-3 recovery threshold alone. Distinct keys are now
   required on encode and decode. Test: `packages/capabilities/src/reducer.test.ts`.
2. **Daemon crash during shutdown** (`patches/async-append-only-log@4.3.10.patch`).
   ssb-db2's close hook closes the append-only log before secret-stack closes
   peer connections, so EBT could append a replicated message after `close()`
   started. The debounced block writer then wrote to the closed file and threw
   an uncaught `Error: Closed`. The log now rejects appends once closing starts;
   peers resend after restart. Test: `packages/transport-ssb/src/journal-recovery.test.ts`
   (fails on `caa8dcb`, passes now). Found by `pnpm chaos:smoke`.
3. **Permanent lockout after an unclean restart in a container**
   (`apps/chronologd/src/data-lock.ts`). The stale-lock check trusted any live
   PID. A restarted container gets a fresh PID namespace, so the replacement
   daemon routinely receives the dead owner's PID and refused to start with
   `DATA_DIRECTORY_LOCKED:<pid>:daemon` (reproduced with the chaos image).
   Locks now record the Linux process start time; a live PID with a different
   start time is treated as stale. Lock files written before this change have
   no start time and still need one manual removal after an unclean exit.
   Test: `apps/chronologd/src/data-lock.test.ts`.
4. **Secret leakage into errors** (`apps/chronologd/src/secret-store.ts`). The
   Linux Secret Service `set` path included up to 512 characters of
   `secret-tool` stderr in its error. It is now redacted like the other
   providers. Test: `apps/chronologd/src/secret-providers.test.ts`.

## New features and tooling

- **Key providers** (`apps/chronologd/src/secret-store-{macos,windows,command}.ts`,
  `secret-common.ts`): macOS Keychain via `security -i`, Windows DPAPI file
  store via PowerShell, and an absolute-path command hook for PKCS#11/YubiKey
  helpers. Values travel on stdin; writes are read back. Opt-in and
  **unverified on real macOS, Windows or hardware** — tested with fakes only.
  Residual exposures are listed in [governance](governance.md).
- **Drill evidence** (`pnpm drill`, `tools/drill.ts`, `tools/lib/drill-evidence.ts`):
  signed records for the custodian, snapshot-repair, multi-host blob,
  traversal, alert, upgrade and external-review drills, plus an offline
  verifier and a release gate that currently reports all seven as MISSING.
  Adds the `chronolog/drill-evidence/v1` signing domain. See
  [drill-evidence.md](drill-evidence.md). It cannot prove signers are distinct
  people or that a drill happened.
- **Review packet** (`tools/lib/review-packet.ts`): library only, untested, not
  wired to a script. It also needs fuzz/sanitizer JSON report output that does
  not exist yet.

## Open items, in suggested priority order

1. **Chaos smoke still fails.** After fixes 2 and 3 every state, schema, log,
   ledger and result invariant passes and all three nodes report identical
   digests, but `waitForConvergence` never sees three consecutive stable polls:
   one node's `ingestionBacklog` (transport records minus processed records)
   stays above the tolerance `max(4, 2 × peers)` — 5 in one run, 41 in another.
   Unresolved: whether this is transient heartbeat load (1s interval, three
   nodes) or records stuck in the ingestion retry set. Graceful shutdown under
   chaos also still hangs until Docker's 15s SIGKILL (prints a bare
   `undefined`); a standalone daemon stops in ~0.2s. One run also failed the
   migration-coverage invariant because the migration operations landed on the
   restarting node. Artifacts are under `.chaos/` locally (ignored).
2. **Validator floor on same-revision revoke and grant (design decision).**
   The reducer appears to ignore validators revoked in the same revision when
   computing the timestamp floor, so revoking a high-floor validator and
   granting a low-floor one together may reopen history without the recovery
   reopening flag. Not confirmed by a test.
3. **Tie completion is not injective.** `completeOrderedResultSql` appends
   `COLLATE BINARY` keys, but `1`/`1.0` and `-0.0`/`0.0`/`0` compare equal, so
   their relative order follows physical scan order. Deterministic only while
   replicas' physical state is identical. Suspected but unverified for
   `group_concat(... ORDER BY ...)` and `GROUP BY` output on mixed numeric or
   `NOCASE` values. Keep the gated SQL surface gated until resolved.
4. **Workerd path timestamp bug.** DoltLite treats a commit date of
   `1970-01-01T00:00:00` as unset and uses wall-clock time;
   `runtime-workerd/src/host-client.ts` uses exactly that default, so commit
   hashes would not be reproducible. The native production path does not pass
   a date and is not affected. `@dolthub/doltlite-wasm@0.11.29` lacks
   sqlite-vec and crashes in `sqlite3_js_db_export`.
5. **Control-store write amplification.** `control.json` and
   `feed-continuity.json` are rewritten and fsynced in full per ingested
   record, so cost grows with history. Relevant for long pilots.
6. **Coverage gaps in security-relevant code:** `node-core` capability
   membership resolver (~25%), `cipher.ts` (61%), `materializer-doltlite`
   `portable.ts`/`snapshot-evidence.ts` (<10%), `rpc/http.ts` (60%).
   `capabilities/admission.ts` is now tested but unused by the repo.
7. **Not run here:** native sanitizers (need clang, or gcc plus
   `LD_PRELOAD=$(gcc -print-file-name=libasan.so)`; break the doltlite
   package hardlinks first), a complete soak, the macOS CI legs, and a real
   cross-version upgrade.
8. **Blob garbage collector** — designed, not built.
9. **Parser:** SQLite 3.53 and 3.54 grammars are equivalent (`parse.y` rules,
   tokenizer and keyword table unchanged); no newer `sqlite3-parser` exists.
   The ledger entry can be narrowed to the semantic 3.54 changes once
   differential fixtures cover them (ALTER on rowid-alias names, authorizer on
   DEFAULT functions, new date modifiers and printf conversions, single-element
   `IN (... COLLATE ...)`).
10. **Human-only release gates:** independent custodian handoff and drill,
    witnessed snapshot-repair/blob/traversal/alert drills, an upgrade from a
    published prior release (none exists), and the external security review.
